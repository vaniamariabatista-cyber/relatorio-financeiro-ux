# Checklist para concluir no Power BI Desktop

Marque os itens somente depois de executar e verificar cada etapa.

- [ ] Abrir `relatorio_financeiro_base.pbix` no Power BI Desktop.
- [ ] Usar **Salvar como** e guardar uma cópia com nome de versão final.
- [ ] Revisar posicionamento, alinhamento, margens e agrupamento dos visuais.
- [ ] Revisar contraste de títulos, textos, cartões e estados de foco/seleção.
- [ ] Conferir os filtros e a segmentação dos dados.
- [ ] Criar a terceira página `Detalhamento`.
- [ ] Criar uma matriz de descrição de vendas.
- [ ] Criar menus de navegação em todas as páginas.
- [ ] Configurar botões para navegar e destacar a página selecionada.
- [ ] Testar todos os botões, filtros e interações cruzadas.
- [ ] Conferir se o relatório tem três páginas e se os elementos continuam legíveis.
- [ ] Salvar o PBIX final, capturas de tela das três páginas e este README no GitHub.
- [ ] Enviar o link do repositório na DIO.
